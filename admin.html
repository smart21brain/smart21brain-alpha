Content management

Want more content on the site? Here's how to add it:
  • More games — use the Add Game tab below. Each one publishes straight to the Games page, no review step.
  • More videos — use Post Video: upload a file or paste a YouTube/Vimeo/CDN link, then tick where it should show.
  • More courses — use Add Course below to create the course, then use the curriculum manager underneath the course list to add its lessons.
  • More blog posts — use Add Blog Post, write the content, and hit Publish.
Teachers are always listed as the instructor of courses they create.
